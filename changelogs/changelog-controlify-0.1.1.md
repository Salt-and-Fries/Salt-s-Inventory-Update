# Salt's Inventory Controlify 0.1.1

- Rebuilds every version/loader artifact against Core API 6, with no calls to removed minimize or ghost-pin API members.

- Requires **Salt's Inventory Update Core 0.1.5** across all twelve supported Minecraft and loader targets, including the Minecraft 1.20.1 Fabric and Forge builds.
- Uses Core's alternative-workspace onboarding behavior so the regular-window tutorial does not interrupt first-world entry, including before a controller is connected.
- Keeps manual help available and preserves the existing controller workspace, crafting and recipe wheels, native keyboard, inventory interactions and status-effects tray.
- Works with the optional **Compatibility 0.1.2** extension for the same Minecraft version and loader.

Install the matching Core, native Controlify mod, this companion and their required dependencies. Fabric also requires the matching Fabric API. Core and upstream dependencies are separate downloads.

Use this same changelog for every Controlify 0.1.1 Minecraft/loader artifact.
