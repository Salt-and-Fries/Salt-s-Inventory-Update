# Salt's Inventory Controlify 0.1.2

- Requires **Salt's Inventory Update Core 0.1.6** on all twelve supported Minecraft and loader targets. The matching **Compatibility 0.1.3** extension is optional.
- Identifies the controller workspace as a screen with its own recipe interface. Compatible recipe browsers can keep their automatic overlays off the workspace while supplying recipes and search to the controller UI.
- Fixes resource-pack metadata for Minecraft **1.21.11 Fabric and NeoForge**.
- Declares the minimum Mixin version for the companion's hooks, resolving a missing-version startup diagnostic on Forge.

Install the companion, matching Core, upstream Controlify and its required dependencies. Fabric also requires Fabric API.
