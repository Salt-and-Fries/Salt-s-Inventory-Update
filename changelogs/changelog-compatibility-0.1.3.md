# Salt's Inventory Compatibility — 0.1.3

Candidate verification, independent review and publication status are recorded in [RELEASE_READINESS.md](../RELEASE_READINESS.md) and the [release manifest](../output/release-readiness/release-manifest-final.json).

- Protects Gallery's complete held painting stack while its selector is open.
  Native search and selection use the owning window session, and closing keeps
  the exact native variant and item data. Applies to 1.20.1 Forge and 1.21.1
  NeoForge; the Core public API and ordinary native screen remain unchanged.
- Fixes Bountiful Analyzer refresh after decree insertion or removal on
  1.21.1 Fabric and NeoForge, retaining native mode and resolution controls.
- Preserves the canonical carried stack when Traveler's Backpack replaces its
  settings menu. The native callback commits its cursor mirror only while its
  original session remains live; Core's strict session checks stay unchanged.
- Declares the required Mixin minimum versions for Compatibility's optional
  integrations across all twelve targets.

- Uses additive public Core contracts for Aether, Quark backpack pairing,
  aircraft attachments and Traveler's Backpack embedded-menu controls. Linked
  panels retain their approved parent ownership and equipment panels remain
  mutually exclusive.
- Preserves Fabric's optional packet connection context when Tom's Storage
  serializes terminal items, including with Polymer installed. The native wire
  format and public API remain unchanged by this codec fix.

- Keeps Tom's native vertical sidebar input regions aligned with its rendered
  controls and clears obsolete horizontal hit regions.
- Avoids resolving unsupported older bundled Curios menu classes from the
  Aether launcher on Forge 1.20.1.
- Targets the concrete AE2 client network handler on Minecraft 1.20.1 instead
  of attempting to mix into its interface.
- Corrects the BetterEnd smelter native crop on the affected 26.x releases.

- Adds Tech Reborn windows on every official release overlapping SIU targets:
  1.20.1, 1.21.1, 26.1.2, 26.2 and 26.3 Fabric. Keeps native artwork, complete
  opaque upgrade trays, inspectors, original actions and live properties.
  Includes the newer Nuclear Reactor and its native fuel-column restrictions.

- Aligns Extended AE IO Port and Mod Export Bus frame bottoms with their upgrade
  trays, and restores native top-right tabs above the frame on every supported
  target. Retains their exposed click areas and original artwork.

- Adds Extended AE windows across 1.20.1 Fabric/Forge, 1.21.1 NeoForge and
  26.1.2 NeoForge. Modern versions retain modern AE2 artwork, native controls,
  side tabs and configuration modes. Preserves complete slot rims, terminal
  updates and native actions without changing Core or the public API.

- Extends the Kibe layouts to 1.21.1 Fabric/NeoForge with the shared generator
  menu, native data components and newer rune glyphs. All official Kibe release
  targets overlapping SIU are covered, including the existing 1.20.1 Fabric build.

- Adds the thirteen Kibe container screen types on 1.20.1 Fabric, including all
  ten generator tiers, with matching native palettes, full slot rims, live rune
  channels and XP conversion. Preserves held Cooler editing and source safety,
  existing Pocket Crafting support and native non-container screens.

- Adds Simply Swords' Runic Forge on Minecraft 1.20.1 Fabric and Forge, with charcoal bars and native torn stone artwork. Preserves weapon/gem/tablet editing, preview tooltips, glowing channels and the original take-to-apply workflow.

- Adds Chipped's seven workbenches on Minecraft 1.20.1 Fabric and Forge, with a matching brown workshop, material picker, searchable variants, scrollbar and native preview modes. Craft and Craft All convert existing inventory stacks in place, with stale selections and workbench lifetime handled safely.
- Keeps the complete Unlink Gear grindstone artwork and Upgrade Gear armor-stand preview visible on Minecraft 1.20.1. Selected workstation tabs connect directly to their window frames at the left edge, and both grindstone views retain their full top outline.
- Adds compact Minecraft 1.20.1 desktop layouts for ExtendedDrawersAddon, BetterEnd, TieredZ, SmitherZ and AdditionZ on Fabric, The Graveyard containers and Runes on Fabric/Forge, and Deep Aether's Combiner on Forge.
- Preserves native recipes, processing, previews, upgrade controls and item rules in compact windows. Workstation tabs sit outside the frame; recipe-book toggles stay inside. Gravestone text editing keeps its normal sign-style screen.

- Prevents newer Alloyed worlds from failing to load when its optional Create-based knife recipe is unavailable. The recipe remains available when Alloyed, Farmer's Delight and Create are installed.
- Preserves the standalone Alloyed forge's processing and Alloy Forgery's newer slot locks and live indicators in their desktop windows.
- Extends these native templates to every later supported target with a matching upstream release, including the standalone Alloyed 3.x forge. Parchment identifying tables, in-frame recipe buttons and compact native controls follow the installed mod release.
- Adds desktop support for Iron Chests: Restocked and Animal Feeding Trough.
- Adds compact Minecraft 1.20.1 desktop layouts for Bartering Station, Farmer's Delight / Refabricated, Better Archeology, Illager Invasion, Galosphere and Sawmill on Fabric and Forge, plus Alloy Forgery and Fabric Seasons: Extras on Fabric and Miner's Delight on Forge.
- Preserves native processing indicators, recipe selection, search, fuel controls and item rules in these layouts. Cooking recipe buttons sit inside widened pot windows; Alloy Forgery's lava reservoir remains outside the main frame.
- Adds compact native layouts for Oxidized, Brick & Mortar, Expanded Delight, Crabber's Delight, Nether Chested and Inmis wherever matching upstream releases are available.
- Fits windows around their actual controls and slot grids, removing excess empty space. Larger layouts use scrolling when needed.
- Gives Better Archeology's identifying table a matching parchment frame and controls, while keeping its native artwork, slots and processing.
- Keeps Brick & Mortar's animated recipe preview outside the kiln's top border, with the main body staying in place as it opens.
- Preserves native artwork, processing, recipe controls, tooltips and item restrictions. Nether Chested uses standard inventory cell backgrounds while retaining large-stack counts and transfers.
- Supports every default Inmis backpack shape, including sorting in the three-slot Baby Backpack.
- Preserves feeding trough interactions and closes its desktop window when the source is destroyed, replaced or out of range.
- Supports sorting, transfers and resizing for all fifteen Iron Chests chest/barrel variants, including restricted Dirt Chest storage and larger Netherite grids.

Requires **Core 0.1.6** for the same Minecraft version and loader. Install the supported third-party mods and their dependencies separately. Fabric requires Fabric API. Upstream availability differs by Minecraft version and loader; see the compatibility page for the supported combinations.

Use these same notes for every Compatibility 0.1.3 artifact.

Known upstream limitation: SmitherZ1.0.4 on Minecraft1.20.1 Fabric previews a recovered gem but loses it during native grinder result pickup. The same exact-jar behavior is confirmed with every SIU module absent. This release does not claim a fix or guaranteed gem return on that pin; see the release notes and native control663.

- Records the exact Simple Storage Network 1.13.2 upstream filter limitations
  on 1.20.1 Forge, 1.21.1 NeoForge and 26.1.2 NeoForge, independently reproduced
  with SIU absent on each pin. Source removal retains both native menus; the
  Collector ghost display stays blank while its server filter persists.
  Right-click with the same carried item re-copies one ghost. Ordinary close,
  full item data and physical ownership have separate focused checks; no SIU
  repair of those upstream behaviors is claimed.

- Records the SSN 1.13.2 / 1.21.1 and 26.1.2 NeoForge original process-cable
  redstone icon/client-state mismatch and persistent native source lifetime,
  reproduced with SIU absent on both pins. Native server settings and full
  item ownership remain checked. No upstream repair, immediate icon sync or
  processing-automation coverage is claimed.
