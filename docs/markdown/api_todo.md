# API follow-up intake

The API6 contract, including the 0.1.5 window-feature removals, is documented in [the current API guide](desktop_window_api.md). Shared authenticated inventory companions, lifetime ownership, source identity/invalidation, enforced drag-only policies and manager controls inside original mod-owned artwork are implemented. Scoped clipping/transforms, native rendering, external interaction regions, client-only views, explicit constraints, structured diagnostics and virtual-row scrolling remain available. Companion and management examples are distributed with the documentation, including an optional runnable consumer.

Record concrete integration requests here with a mod/use case, the behavior needed, an example, its current workaround and the Minecraft/loader targets. Future additions should be based on actual integration evidence. Candidate areas include variable-height/async virtualization helpers, IME adapters and reusable full-screen bridge utilities for particular UI frameworks. Native widget narration, semantic labels and keyboard traversal are implemented. The candidate additions are not advertised as completed generic features.
