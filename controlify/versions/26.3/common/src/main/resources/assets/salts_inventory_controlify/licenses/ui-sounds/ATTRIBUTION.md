# UI recordings

The seven redistributed recordings and their derived versions are **CC0-1.0**, by Kenney.

- **Interface Sounds (1.0)** — Kenney, <https://kenney.nl/assets/interface-sounds>
- **UI Audio / UI SFX Set** — Kenney Vleugels (Kenney.nl), <https://kenney.nl/assets/ui-audio>
- CC0 dedication: <https://creativecommons.org/publicdomain/zero/1.0/>

The original notices are included unchanged beside this document as `kenney-interface-sounds-License.txt` and `kenney-ui-audio-License.txt`. `palette-manifest.json` records each original archive member, source hash, derived hash, processing parameters and numerical measurements.

Derived recordings use mono downmix where needed, fixed attenuation and short edge fades. Only `craft_complete.ogg` is shortened, to 140 ms with a 24 ms end fade. No Minecraft, console-game, Bedrock or other mod recordings are redistributed. These are new CC0-derived companion cues, not claimed reproductions of those games' audio.

Editable originals and the rebuild tool are in the project's `controlify/versions/26.3/common/audio-source/`, outside the production resources. Companion event IDs use the `salts_inventory_controlify` namespace. `ui.open` and `ui.close` are aliases to the existing `minecraft:ui.button.click` event. No Minecraft audio is redistributed, and the CC0 dedication above does not apply to Minecraft's recordings.
